## Task

Implement `greet(name: str) -> str` in `greet.py` so it returns a friendly greeting.

## Constraints

- Keep the function in `greet.py`
- Do not add external dependencies
- Greeting format must be exactly: `Hello, {name}!`

## Acceptance Criteria

1. `greet("World")` returns `"Hello, World!"`
2. `greet("Ada")` returns `"Hello, Ada!"`
3. Calling `greet` with an empty string returns `"Hello, !"`
