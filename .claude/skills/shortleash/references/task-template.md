# Task template for Shortleash

```markdown
## Task

Implement <feature> in <path/module>.

## Constraints

- Do not add new dependencies
- Keep public API stable
- Touch only files under <scope>

## Acceptance Criteria

1. <concrete observable behavior>
2. <edge case>
3. <error / empty input behavior>
```

Bad criteria (too vague): «works correctly», «good UX», «clean code».  
Good criteria: exact return values, status codes, file/function names, error types.
